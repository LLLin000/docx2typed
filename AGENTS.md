## Agent skills

### Issue tracker

GitHub Issues in `LLLin000/docx2typed-typed-mode`; external PRs are not a triage request surface. See `docs/agents/issue-tracker.md`.

### Triage labels

Canonical labels use the default names: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context repo: read root `CONTEXT.md` and relevant `docs/adr/` entries. See `docs/agents/domain.md`.
